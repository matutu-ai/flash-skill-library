# 拾景 Zine · 影像创作集合

这是 Zeejay0 创作的影像再创作 Skill 集合。当前远端 `main` 的 `skills/` 目录包含三个正式入口；本站遵循“一仓库一卡”，因此只建立一张集合卡，并在卡内保留三个入口的原文副本。

## 三种创作路径

- [实景拼贴](./upstream/skills/scenes-gathered-zine-v1-3/SKILL.md)：保留真实照片作为视觉锚，用抽象插画、结构性色彩、留白和手撕纤维边界扩展现场。
- [影像蒸馏](./upstream/skills/scene-distillation-zine-v1-3/SKILL.md)：照片只提供事实与情绪来源，成品不嵌入原始摄影，而是重新创作独立纸上作品。
- [莫兰迪电影海报](./upstream/skills/morandi-cinematic-poster-zeejay/SKILL.md)：忠于原照片，通过电影标题、字体层级、负空间和选择性遮挡建立海报感。

## 需要输入

- 一张用户提供的真实照片
- 希望保留的主体关系、文字语言或情绪方向
- 是否希望保留照片本身，或是否明确需要电影海报版式

## 输出

- 纸感实景拼贴海报、影像蒸馏原创插画或莫兰迪电影感摄影海报
- 所选子 Skill 规定的简短创作说明或艺术指导说明

## 使用方法

1. 复制 [prompt.md](./prompt.md) 中的调用提示词。
2. 先阅读 [SKILL.md](./SKILL.md) 集合索引，选择最符合需求的一个子 Skill。
3. 打开该子 Skill 的原文入口并按其完整规则执行。

## 文件说明

- `skill.yaml`：一仓库一卡的标准化网站元数据。
- `README.md`：集合用途、三条路径与使用入口。
- `prompt.md`：最小可复制调用提示词。
- `SKILL.md`：本站创建的集合索引；不是上游单 Skill 入口。
- `upstream/skills/*/SKILL.md`：逐字节保存的三个远端正式子 Skill。
