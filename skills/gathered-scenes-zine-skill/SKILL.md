# 拾景 Zine · 影像创作集合索引

> 集合索引说明：本文件是本站为“一仓库一卡”创建的路由索引，不是上游仓库的正式单 Skill 入口，也不合并或改写任何子 Skill。执行创作前，必须打开所选子 Skill 的原文入口。

## 选择一个子 Skill

### 实景拼贴 · Gathered Scenes

当用户希望保留原始摄影及现场身份，并用抽象插画、结构性色彩、留白和手撕纸边界扩展画面时，使用 [scenes-gathered-zine-v1-3](./upstream/skills/scenes-gathered-zine-v1-3/SKILL.md)。

### 影像蒸馏 · Scene Distillation

当用户希望从照片提取语义、情绪张力和视觉隐喻，但不在成品中保留原始摄影时，使用 [scene-distillation-zine-v1-3](./upstream/skills/scene-distillation-zine-v1-3/SKILL.md)。

### Morandi Cinematic Poster

当用户希望忠于原始照片，并通过标题设计、字体层级、负空间、透视对齐和选择性遮挡形成电影海报时，使用 [morandi-cinematic-poster-zeejay](./upstream/skills/morandi-cinematic-poster-zeejay/SKILL.md)。

一次任务只选择一个入口。选择后，以对应原始 `SKILL.md` 的输入、约束、输出和授权规则为准。
