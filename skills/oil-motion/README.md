# Oil Motion

Oil Motion 将滚动、拖拽等交互意图转换为可验收的视觉方案、动画素材、时间轴和网页运行时。它适合需要画面随输入推进、停止和反向退回的网页体验。

## 需要输入

- 页面用途、主体与视觉风格
- 滚动、指针、拖拽、触摸等交互方式
- 目标设备、页面位置和最大显示尺寸
- 已有图片或视频素材（如有）

## 输出

- 视觉与交互方案
- 关键帧及动画生产计划
- 素材时间轴与网页运行时

## 使用方法

1. 复制 [prompt.md](./prompt.md) 中的调用提示词。
2. 将页面主题、主体、风格和交互结果替换为你的真实需求。
3. 提供目标设备及已有素材，让 Skill 确定画幅、关键帧和播放方式。
4. 按 [SKILL.md](./SKILL.md) 的 Pilot、媒体选择和最终验收流程执行。

## 文件说明

- `skill.yaml`：供网站索引与详情页读取的标准化元数据。
- `README.md`：用途、输入、输出和使用入口。
- `prompt.md`：最小可复制调用提示词。
- `SKILL.md`：原始完整 Skill 说明，是流程与规则依据。
