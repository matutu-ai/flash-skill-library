# Seedance Cinematic Director · 电影叙事导演

这个 Skill 把故事、Brief 或参考素材转化为可制作的电影级视频导演方案。它先分析戏剧目标、人物表演、镜头、光线、空间和物理连续性，再编译成可复制的模型提示词并评分。

源仓库：[matutu-ai/seedance2.5-AIdy](https://github.com/matutu-ai/seedance2.5-AIdy)

## 如何在豆包中使用

1. 打开豆包，新建对话，上传或粘贴本技能的 `SKILL.md`。
2. 切换模式：点豆包输入框左下角的「云电脑」，选「工作任务 · 云电脑」。
3. 再提供故事/Brief 和参考素材，并写明已知的模型、时长、画幅与必须保留的元素。
4. 明确说要中文导演说明、完整 Prompt 和质量评分，并给出时长与画幅。
5. 缺参数就回「没有 / 待补」，允许保守假设但必须标明，不要虚构平台能力。
6. 复制导演说明与 Prompt；只改不合格部分即可。
7. 把定稿 Prompt 贴到目标模型入口生成；换故事请新开对话。
