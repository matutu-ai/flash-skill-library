# AI Native Dark SaaS UI

为 AI SaaS、Agent 平台、开发者工具、开源社区、Skill 市场和创作者平台设计高级深色界面，提供页面结构、组件拆分、设计 tokens、动效与响应式方案，并遵循现有项目技术栈。

## 使用入口

1. 先确定主要用户、主要动作和页面类型。
2. 输出页面结构、组件职责、视觉 tokens、动效和响应式策略。
3. 按现有技术栈实现，不额外引入不必要的包、3D 场景或动画库。
4. 检查可读性、键盘操作、移动端和减少动态效果模式。
