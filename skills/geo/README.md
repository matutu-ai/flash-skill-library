# GEO V3 · 企业增长闭环

这个 Skill 把企业资料组织成可执行、可验证、可持续优化的 GEO 增长系统。它覆盖资料清洗、证据管理、企业 Profile、关键词矩阵、九大画像、内容发布、验证与缺口补强，并通过 `INDEX.md` 按任务读取仓库中的最少文件。

## 需要输入

- 企业介绍、产品或服务资料、案例与资质等事实材料
- 图片、docx、xlsx、文本或网页链接
- 本次需要生成、调整、批量处理或验证的目标

## 输出

- 企业 GEO Profile、事实与证据记录
- 关键词矩阵、九大画像与垂直业务画像
- 内容矩阵、动态发布策略、验证结果与缺口队列

## 使用方法

1. 复制 [prompt.md](./prompt.md) 中的调用提示词。
2. 先加载 [SKILL.md](./SKILL.md)，再按入口规则通过 `INDEX.md` 读取所需模块。
3. 提供企业资料；缺失内容保留为缺失项或待验证项。
4. 在每个交互节点选择下一步，逐步完成简约版、完整版、垂直画像或验证流程。

## 文件说明

- `skill.yaml`：一仓库一卡的标准化网站元数据。
- `README.md`：用途、输入、输出与使用入口。
- `prompt.md`：最小可复制调用提示词。
- `SKILL.md`：逐字节保存的远端 `main/SKILL.md` 正式入口。
