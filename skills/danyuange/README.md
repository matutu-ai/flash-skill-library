# 国际版 GEO · 九大单元

这个 Skill 把客户的国际版 GEO 下单资料整理为标准九大单元交付。它先依据真实填写内容判断客户是制造商还是服务商，再选择对应官方模板，导出结构完全一致的英文原版与纯中文分析版，并把缺失资料单独列出。

## 需要输入

- 国际版 GEO 下单表，或制造行业、服务行业九大单元资料
- 仓库提供的制造商或服务商官方 xlsx 模板
- 与模板配套的字段映射和格式约束

## 输出

- 英文原版九大单元工作簿
- 纯中文分析版九大单元工作簿
- 独立补充资料清单

## 使用方法

1. 复制 [prompt.md](./prompt.md) 中的调用提示词。
2. 提供客户填写资料及仓库中的模板和 references。
3. 让 Skill 先给出客户定位及真实字段依据，再生成三项交付物。
4. 按 [SKILL.md](./SKILL.md) 的结构一致性与真实性规则复核结果。

## 文件说明

- `skill.yaml`：一仓库一卡的标准化网站元数据。
- `README.md`：用途、输入、输出与使用入口。
- `prompt.md`：最小可复制调用提示词。
- `SKILL.md`：逐字节保存的远端 `main/SKILL.md` 正式入口。

源仓库：[matutu-ai/danyuange](https://github.com/matutu-ai/danyuange)

许可证：仓库未声明。

## 如何在豆包中使用

1. 打开豆包，新建对话，上传本技能的 `SKILL.md`、官方模板 xlsx 和说明文件。
2. 切换模式：点豆包输入框左下角的「云电脑」，选「工作任务 · 云电脑」。
3. 再上传客户已填的下单表或九大单元资料。
4. 明确说：「先判断制造还是服务，再导出英文原版和纯中文分析版，缺失资料单独列清单。」
5. 缺字段回「没有 / 待补」，不要编造；对应格留空并进清单。
6. 下载两份工作簿和缺失清单，核对是否与客户原文一致。
7. 可补缺后重导；换客户请新开对话。
