# 国际版GEO九大单元（跨平台通用版）

把本文件与 `assets/manufacturer-nine-unit-template.xlsx`、`assets/service-provider-nine-unit-template.xlsx` 一起交给任意 AI 平台使用。客户资料以 `国际版GEO下单表9-1.xlsx` 类文件为准；AI 只需要在收到资料后执行以下固定流程，不需要额外猜测或自行扩展内容。

### 豆包 / 千问 / 其他平台用法

1. 上传本 SKILL.md、两个官方模板 xlsx、references 文件夹，再上传客户的“国际版GEO下单表”或客户已填写的制造/服务九大单元表。
2. 对 AI 说：“请按九大单元 skill 执行：先判定制造还是服务，再严格导出英文原版和纯中文分析版两份九大单元，缺失资料单独列清单。”
3. 下载 AI 输出的两份 xlsx，对照下面的自查项核验后再交付。

如果平台不能上传整个文件夹，就把 `references/` 里的三个 md 与 `assets/` 里的两个模板 xlsx 逐个上传，再上传客户下单表。

## 第一步：判定客户类型

先判定客户是制造商还是服务商，判定依据只有客户实际填写的内容，不得根据模板示例、填写说明、参考案例猜测。

打开资料表，按以下规则判定：

1. 客户填了“制造行业-九大单元表”/“制造业-制造商九大单元资料”，内容出现工厂、OEM、产能、月产能、MOQ、规格型号、材质、证书编号、交期、验收方式等制造特征时，判定为**制造商**，使用制造商模板。
2. 客户填了“服务行业九大单元表格资料”/服务类投喂表，内容以解决方案、方法论、服务流程、咨询项目、客户案例、结果指标为主时，判定为**服务商**，使用服务商模板。
3. 一个文件里同时放了两个表时，看哪个表的内容是客户真实填写的业务资料。模板自带的 `ABC Fan` 示例、D 列“填写参考/填写说明”、示例服务商推导内容、`USD 5000`、`10+ years`、虚拟客户案例等一律不是依据。
4. 先简要输出“客户定位：制造商/服务商 + 判定理由（2-3 条）”，然后直接进入导出，不需要客户再次确认。理由必须引用客户真实填写字段，不引用参考内容。

一个工作簿里如果同时放了制造表和服务表，最终只使用与判定结果对应的那一张表，不得把另一张表的内容混入九大单元。两张表都出现同一字段时，以所选定位表的 C 列为准。

## 第二步：选模板并清空示例行

- 制造商：复制 `assets/manufacturer-nine-unit-template.xlsx`（8 个 sheet）
- 服务商：复制 `assets/service-provider-nine-unit-template.xlsx`（9 个 sheet）

两个模板都自带 `ABC Fan` 示例数据。导出前必须先清空全部示例数据（服务商模板若某 sheet 只有第 1 行表头，也保持表头 + 一行数据行的两行结构），再写入客户真实内容。不得增删、改名或重排 sheet、列、行，不得新增“缺失提示”sheet，不得修改第 1 行字段名。

## 第三步：读取并映射客户内容

客户填写表是“竖排字段表”，常见结构为：

- A 列：所属单元（企业背景单元 / 产品规格单元 / 服务定义单元…，可能以合并单元格出现）
- B 列：字段名（公司名、成立年份…）
- C 列：客户填写的正式内容
- D 列：填写说明、参考示例或图片要求，**不是正文**
- 另有“国际版GEO下单表”前置信息区，包含品牌词、细分训练词、社媒、blog 等补充资料

映射规则：

1. 按字段名匹配到官方模板第 1 行的同名字段；名称完全一致的直接放入该列。
2. 只写客户 C 列真实内容。客户内容里的中文保留中文，英文保留英文；源表已有英文的，英文原版照抄原文，不做拼写“修正”。
3. D 列说明、填表参考、图片要求不写入九大单元正文。
4. 官方模板里客户没填的字段留空；客户表里没有对应官方字段的多余行不导出。
5. 制造商源表的少量字段名与官方模板列名不同，按下表映射；其余字段一律按“字段名相同”处理：

| 源表字段 | 官方模板列 |
|---|---|
| 适合场景 | 适用场景 |
| 数量规模 | 项目规模 |

6. 详细字段映射与两个模板的完整列名见 [references/field-mapping.md](references/field-mapping.md)。

## 第四步：导出两个工作簿

每次任务导出两份 .xlsx：

1. **英文原版**：sheet 名与第 1 行字段名为官方模板中文原样；数据行内容为客户的英文填写内容。客户原稿是英文就照抄，客户原稿含中文说明时仅把其中说明性文字转成英文，数字、规格、证书编号、网址、邮箱、电话等一律不动。
2. **纯中文分析版**：sheet 结构与英文原版完全一致，仅把自然语言内容翻译成中文；数字、百分比、尺寸、型号、系列、证书编号、标准号、日期、网址、邮箱、电话、单位、材料代号等严格原文保留，不增字不删字。中文版存在的意义是让分析人员能读懂事实；能直译的说明文字直译，可保留括号中英对照，但不得自行新增客户未写的数字或故事。

两份文件必须满足：

- sheet 名称、sheet 顺序、第 1 行字段标题完全一致
- 非空/空单元格位置完全一致
- 同一字段中英文版本事实完全等价，不新增、不遗漏、不美化、不改写

## 第五步：单独输出缺失资料清单

缺失清单放在九大单元工作簿之外，单独生成一个 `XX_补充资料清单.xlsx` 或表格文档，包含“单元 / 缺失字段 / 请客户补充什么”。缺失清单只列官方模板字段中没有客户内容的字段；某字段只有图片资料、尚未整理成文字时，也写“请客户提供图片/文字素材”。九大单元工作簿内的缺失字段一律留空，不得写 `N/A`、`TBD`、`待补充`、`-` 等占位符，不得编造数字、案例、认证或评价。

## 交付前自查

1. 客户定位判定依据是否真实可引用。
2. 是否先清空了模板自带示例数据，且每个 sheet 都保持“表头 + 一行数据行”结构。
3. 两个导出版本 sheet 结构、字段标题、空/非空位置是否完全一致。
4. 英文原版是否最大程度保留客户原文；中文版是否保留全部数字与专有标识。
5. 缺失清单是否独立于九大单元工作簿。
6. 是否只填写了客户资料中真实存在的内容。
