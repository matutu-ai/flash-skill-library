# Seedance 2.5 视频提示词描述

## 核心输出

每条提示语按以下顺序输出，直接可复制：

```text
Seedance 2.5｜Xs｜画幅｜fps｜主题｜旁白语言｜BGM状态

【素材说明】
@图片1：用途与作用范围；@图片2：...
@视频1/@音频1：...

【人物锁定】（有人物时）
[不变量列表]；[允许自然变化]；[禁止变化]。

【统一摄影风格】（有风格要求时）
[摄影机行为]；[画面质感]；[剪辑与转场]。

【时间轴】
0-X秒｜标题：[动作因果 + 镜头 + 声音]
X-Y秒｜标题：[动作因果 + 镜头 + 声音]

【声音】
[旁白/对白的说话人、语言、原文、情绪]；[音效与环境声]；[BGM 状态]。

【第一段结束状态】（要作为下一段参考时）
[末帧位置、方向、动作、光线、机位、声音]。

【禁止项】
[按任务写的负向约束]。
```

## 编写规则

1. 素材 token 用平台格式 `@图片N`、`@视频N`、`@音频N`，每张写清唯一用途和作用范围；同时列出不要迁移的内容，例如原背景、水印、文字、人物、原音轨。
2. 人物锁定写可观察不变量：脸、痣、年龄感、体型、发型、服装、鞋；再写允许的自然变化，例如出汗、泛红、发丝松散、衣领湿润；最后写禁止变化，例如换装、换鞋、改变发长、突然恢复干爽。
3. 动作写因果链：准备 → 力量 → 接触 → 反应 → 恢复，不写抽象情绪。对话写说话人、目标语言、原文、情绪和断句，并明确无字幕或字幕文本。
4. 每个新镜头至少 3 秒；快速蒙太奇里的 2 秒镜头只放 1 个动作。标题时长必须等于时间轴覆盖总时长。时间戳用扁平、不重叠的区间，不要在 27-30 里再嵌套 27-28。
5. 机位规则：摆放机位保持极轻微震动，手持机位保持自然抖动；同一段不要推+拉同现；近景不要环绕；不要把「向前移动」和「推开」这类词放在同一句，以免被误判为运镜冲突。
6. 有镜面场景时，明确镜中只出现主角倒影，不出现摄像机、拍摄者或第二人。
7. 有 Logo 或屏幕文字时，用参考图 + 稳定小屏 + 明确“不生成其他 UI”；生成后仍不稳时改用后期合成替换。
8. 结束状态作为交接锚点：写清末帧位置、朝向、手部动作、门/光状态、机位运动和声音。
9. 平台限制以 `seedance-prompt-engineer` skill 的 `references/specs-and-modes.md` 为准；输出前运行下方校验。

## 校验

```bash
python3 ~/.codex/skills/seedance-prompt-engineer/scripts/validate_prompt.py --version 2.5 --mode standard --duration N --prompt-file prompt.txt
```

已知校验问题：
- 嵌套时间戳报“时间轴重叠” → 拍平区间。
- “向前移动”+“推开”被误判为推/拉冲突 → 换词。
- 同一提示词内不同镜头的“前推”与“拉远”也会被误判 → 改用“靠近”“扩大景别”。
- 负向词“不做环绕”与“固定机位”同段可能误报静止/运动冲突 → 属可忽略的假阳性，或换“不做圆周运镜”。
- `{{Mixed 1}}` 这类占位符不算素材 token → 改成 `@图片N`。
