# 珠宝品牌动效制作包

## 核心能力

1. **15 秒珠宝广告视频提示词**：从产品图、宝石/金属信息或品牌调性出发，输出可直接复制到即梦/Seedance 等视频生成平台的完整提示词。
2. **珠宝品牌电影感单页建站方案**：输出 React 19 + TypeScript + Vite 6 + Tailwind CSS v4 的滚动驱动单页网站提示词，或直接实现对应项目。
3. **双交付制作包**：当用户只提供品牌和产品素材时，默认同时给出视频提示词与建站提示词，保持一致的高级珠宝视觉语言。

## 工作流

### 1. 收集必要上下文

只问会改变交付物的关键问题，最多两个：

- 产品是什么：耳环、戒指、项链、手链，或完整套系？
- 是否已有品牌名、Slogan、产品图 URL、定价和文案？

用户没有给出品牌信息时，使用参考模板中的 AURELIA 默认品牌信息，并在输出中标注可替换字段。

### 2. 选择主交付物

| 用户请求 | 主交付物 |
|---|---|
| 珠宝短视频、珠宝广告、产品动效提示词 | 视频提示词 |
| 珠宝官网、品牌单页、AI 建站提示词 | 建站提示词或实现 |
| 珠宝品牌全套内容、同时要视频和网站 | 双交付制作包 |
| 只给了一张产品图 | 默认按耳环+戒指套系处理；如产品明显不同则按产品类型调整 |

### 3. 生成视频提示词

读取 `references/video-prompt.md`，按完整模板输出。必须保留以下不可变约束：

- 15 秒、16:9、一镜到底、无剪辑硬切、无闪光特效。
- 珠宝只呈现天然宝石切面的物理写实反光，禁止星光闪烁、额外发光、夸张珠光。
- 人物皮肤保留真实肌理，禁止过度磨皮或硅胶塑料质感。
- 画面无字幕、无水印、无文字叠加。
- 耳环或核心珠宝特写、手部珠宝特写各固定停顿一秒。

输出时不要让用户自己拼接；直接给一条可复制的最终视频提示词，并附一段简短的分镜时间轴说明。

### 4. 生成建站方案

读取 `references/site-prompt.md`。默认按以下技术约束输出：

- React 19 + TypeScript + Vite 6 + Tailwind CSS v4。
- 页面总高 650vh，所有内容层使用 fixed 定位，滚动位置映射为视觉变化。
- 两个 `<video>` 全屏背景层，48% 处切换，视频可被滚动搓帧。
- 左侧产品面板在 40%-50% 滑入、50%-90% 滑出、90%-100% 再滑入。
- 动画中间值存 `useRef`，只用一个 progress state 驱动面板切换。
- 主色 `#C9A96E`、近黑背景 `#020202`、Instrument Serif + Manrope。

用户要求“建站提示词”时给一条可复制的完整提示词；要求“直接实现”时按模板落地为可运行 Vite 项目并验证 `npm run dev`。

### 5. 输出与验证

输出格式：

```text
## 珠宝品牌制作包
**品牌**：...
**交付物**：视频提示词 / 建站提示词 / 双交付

### 15 秒珠宝广告视频提示词
[可直接复制的完整提示词]

### AI 建站提示词
[可直接复制的完整提示词，或项目说明]
```

交付前按 `references/checklist.md` 检查：时长/比例、一镜到底、珠宝写实、视频搓帧、面板时序、性能约束、品牌字段和可复制性。

## 红线

1. 不夸大视频生成平台能力；珠宝材质细节以“物理写实反光”为准，不承诺像素级控制。
2. 用户未提供品牌信息时使用 AURELIA 默认值，但要明确标出可替换字段。
3. 建站项目不得手写性能差的大状态动画；视频搓帧必须使用 `useRef` 和 `requestAnimationFrame`。
4. 建站提示词必须包含核心素材占位符、产品数据占位符和初始化命令，避免用户事后拼装。
