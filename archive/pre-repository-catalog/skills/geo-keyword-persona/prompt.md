# 可复制 Prompt

## 快速示例

> 使用 GEO 画像选词，为面向中小企业运营团队的客服 SaaS 建立用户画像、关键词矩阵与内容规划；缺失资料请标注假设。

## 可填写模板

> 使用 GEO 画像选词，为以下品牌或产品建立 GEO 核心词策略。
>
> 品牌或产品：[名称]
>
> 行业或赛道：[行业]
>
> 目标用户：[年龄、职业、需求和场景]
>
> 业务目标：[品牌曝光 / 转化 / 用户教育]
>
> 竞品：[竞品名称；未知可留空]
>
> 目标 AI 平台：[例如 ChatGPT、Perplexity、豆包、Kimi、百度 AI]
>
> 请输出用户画像概览、画像与决策阶段关键词矩阵、语义集群与内容规划、核心词汇总和信源建设清单。覆盖认知、考虑、决策与使用阶段；合并高度相似的词，保证至少 30% 为自然语言问句，并明确标注所有假设。
