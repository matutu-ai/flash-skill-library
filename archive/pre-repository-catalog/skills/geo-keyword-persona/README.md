# GEO 画像选词

根据品牌、产品和目标用户建立画像，并把认知、考虑、决策和使用阶段映射为 GEO 关键词、语义集群、内容规划与信源建设任务。

## 输入

- 品牌或产品名称与行业
- 目标用户和核心使用场景
- 业务目标、竞品与重点 AI 搜索平台

## 输出

- 用户画像概览
- 画像与阶段关键词矩阵
- 核心词、长尾问题词和语义集群
- 内容规划与信源建设清单

## 工作流

1. 收集品牌、用户和业务信息。
2. 构建 3 至 5 个典型用户画像。
3. 映射决策阶段与检索意图。
4. 生成四类关键词。
5. 输出内容覆盖和信源建设方案。
6. 检查覆盖范围、词项差异和问句比例。

## 使用方法

填写 [prompt.md](./prompt.md) 中已知的信息；缺失项允许保留，但必须要求输出明确标注假设。完整的行业模板、表格结构和质量规则见 [SKILL.md](./SKILL.md)。
