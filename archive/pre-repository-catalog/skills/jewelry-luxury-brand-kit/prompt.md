# 可复制 Prompt

## 快速示例

> 使用珠宝品牌制作包，为一枚天然蓝宝石戒指设计 15 秒、16:9、一镜到底的广告提示词，并给出配套品牌单页方案。

## 可填写模板

> 使用珠宝品牌制作包，为以下珠宝项目制作内容。
>
> 产品类型：[耳环 / 戒指 / 项链 / 手链 / 套系]
>
> 品牌名称：[品牌名]
>
> Slogan：[品牌标语]
>
> 产品素材：[图片或素材说明]
>
> 产品信息：[宝石、金属、价格与核心卖点]
>
> 品牌调性：[例如克制、现代、电影感]
>
> 交付物：[15 秒视频提示词 / 品牌单页方案 / 两者都要]
>
> 视频请采用 15 秒、16:9、一镜到底，保持珠宝材质与人物皮肤真实，不添加字幕、水印或夸张发光。网页方案请给出完整滚动时序、素材占位和初始化方式。缺少品牌信息时可使用 AURELIA 默认字段，并明确标出需要替换的位置。
