# 珠宝品牌制作包

为珠宝品牌生成 15 秒广告视频提示词、电影感品牌单页方案，或同时交付两者。视频路线强调一镜到底、真实材质与稳定特写；网页路线采用滚动驱动的固定画面叙事。

## 输入

- 珠宝类型与产品图片
- 品牌名称、Slogan 与视觉调性
- 定价、产品文案和目标交付物

## 输出

- 可直接复制的 15 秒珠宝广告视频提示词
- 滚动驱动品牌单页方案
- 视频与网站双交付制作包

## 工作流

1. 收集产品和品牌信息。
2. 判断交付视频、网站或双交付。
3. 按固定约束生成视频提示词。
4. 按滚动时序与技术栈生成网页方案或实现。
5. 检查画幅、镜头连续性、材质、性能和可复制性。

## 使用方法

将产品资料填入 [prompt.md](./prompt.md) 的占位项后提交给支持该 Skill 的 AI 助手。需要完整模板、红线和实现约束时，以 [SKILL.md](./SKILL.md) 为准。
