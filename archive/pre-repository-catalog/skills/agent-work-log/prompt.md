# 可复制 Prompt

## 快速示例

> 使用代理商工作日报，将下面的工作记录整理为五段高亮日报，保留全部代理商名称与问题细节，未办结事项放入待跟进计划。

## 可填写模板

> 使用代理商工作日报，将下面的原始工作记录整理为五段高亮日报。
>
> 要求：
>
> 1. 按“今日核心成果、重点专项工作、分类业务办结、问题复盘优化、明日工作计划”的固定顺序输出。
> 2. 保留全部代理商名称、事项细节和处理状态，同类事项可以归并但不能遗漏。
> 3. 关键数字、代理商名称和重要成果使用 Markdown 加粗。
> 4. 持续或跨天事项放入重点专项，单点完成事项放入分类业务办结。
> 5. 未办结事项放入明日计划；不要根据示例虚构服务数量、闭环率或“无积压”等结论。
>
> 原始工作记录：
>
> [在此粘贴当天记录]
