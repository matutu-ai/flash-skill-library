# 代理商工作日报

将代理商客服或运营团队的零散记录归并为五段中文日报，保留全部代理商名称和事项细节，并突出真实数据、处理结果与待跟进任务。

## 输入

- 当天原始工作记录
- 代理商名称、处理状态和关键数据
- 技术工单、持续专项与明日待办

## 输出

- 今日核心成果
- 重点专项工作
- 分类业务办结
- 问题复盘优化
- 明日工作计划

## 工作流

1. 通读记录并识别全部事项。
2. 合并同类事项。
3. 区分持续专项与单点办结事项。
4. 按五段固定结构输出并高亮数据。
5. 复核名称、状态和待跟进项，避免遗漏或虚构。

## 使用方法

把未经整理的记录粘贴到 [prompt.md](./prompt.md) 的末尾。数字、闭环率和处理状态只能来自原始记录；信息不足时应保留为待确认。完整格式和写作规则见 [SKILL.md](./SKILL.md)。
