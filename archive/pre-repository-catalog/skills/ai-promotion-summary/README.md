# AI 推广总结

为品牌或客户整理品牌词与业务词，并给出问答内容、信源一致性、执行优先级和持续监测建议。

## 输入

- 品牌全称、简称和门店名
- 希望覆盖的搜索场景
- 目标客群、服务卖点和定位区域

## 输出

- 6 至 10 个品牌词
- 品类、地域、组合与问题词
- 内容、信源、优先级和监测建议

## 工作流

1. 收集品牌和业务信息。
2. 输出统一的品牌词。
3. 按客群、服务和地域生成四类业务词。
4. 给出问答内容与信源一致性建议。
5. 排定执行优先级并制定监测动作。

## 使用方法

填写 [prompt.md](./prompt.md) 后提交给支持该 Skill 的 AI 助手。结果用于制定推广策略，实际曝光需要结合各平台搜索结果持续验证。完整规则和输出模板见 [SKILL.md](./SKILL.md)。
