# Seedance 2.5 提示词描述

这个 Skill 用固定中文结构整理素材说明、人物锁定、摄影风格、时间轴、声音、结束状态和禁止项，适合强调角色连续性与镜头节奏的视频项目。

## 需要输入

- 视频主题、时长和画幅
- 人物与场景参考
- 摄影风格
- 旁白、对白、环境声和 BGM 要求

## 输出

- 结构化视频提示词
- 人物与摄影连续性约束
- 时间轴及片段结束状态

## 使用方法

1. 复制 [prompt.md](./prompt.md) 中的调用提示词。
2. 替换主题、时长、画幅、人物和声音要求。
3. 如有素材，按 `@图片N`、`@视频N`、`@音频N` 提供并说明用途。
4. 按 [SKILL.md](./SKILL.md) 的固定结构输出，并使用配套校验器检查。

- `skill.yaml`：供网站索引与详情页读取的标准化元数据。

- `prompt.md`：最小可复制调用提示词。
- `SKILL.md`：原始完整 Skill 说明，是模板与校验规则依据。
