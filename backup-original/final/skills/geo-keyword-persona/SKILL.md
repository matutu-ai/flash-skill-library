# GEO画像选词

为品牌/产品生成GEO（Generative Engine Optimization，生成式引擎优化）核心词策略，基于用户画像套用模版完成关键词选词、聚类和内容覆盖方案。适用场景：需要为产品做AI搜索引擎（ChatGPT、Perplexity、Google AI Overviews、百度AI、Kimi、豆包等）内容优化、关键词策略规划、或用户画像驱动的选题策划。

## 核心概念

GEO不同于传统SEO：AI引擎不依赖爬虫抓取和反向链接排序，而是基于训练语料、RAG检索增强生成和结构化语义理解来引用内容。因此关键词策略需要从「搜索引擎分词匹配」转向「AI可理解的语义意图匹配」。
传统关键词追求密度和排名，GEO关键词追求语义覆盖、信源权威度、引用概率。

## 使用场景

当用户提出以下需求时自动激活本技能：
- "帮我做GEO关键词/画像选词"
- "给XXX产品生成GEO核心词"
- "用画像套词选GEO词"
- 提供产品/品牌名、目标用户信息，需要关键词策略

## 工作流程

### 第一步：信息收集

从用户处获取或推断以下信息（缺省时合理假设）：
1. **产品或品牌名称**：具体产品/服务是什么
2. **行业/赛道**：属于哪个垂直领域
3. **目标用户画像**：核心用户是谁（年龄/职业/需求/场景）
4. **业务目标**：品牌曝光？转化？用户教育？
5. **竞品**：直接竞品有哪些
6. **目标AI引擎**：侧重哪个平台（默认覆盖主流：ChatGPT、Perplexity、豆包、Kimi、元宝、百度AI等）

### 第二步：用户画像建模

为产品构建3-5个典型用户画像，每个画像包含：

| 维度 | 内容 |
|------|------|
| 画像名称 | 简洁标签，如「新手宝妈」「技术决策者」 |
| 人口特征 | 年龄、性别、城市等级、收入水平 |
| 需求场景 | 在什么场景下产生需求（when/where/why） |
| 决策阶段 | 认知期 / 考虑期 / 决策期 |
| 核心痛点 | 最想解决的1-3个问题 |
| 信息获取习惯 | 倾向于搜索什么类型的问题、用什么平台 |

### 第三步：画像->关键词映射

将每个画像映射到对应的关键词类型和检索意图：

| 决策阶段 | 检索意图类型 | 关键词形态 | 示例 |
|---------|-------------|-----------|------|
| 认知期 | 问题诊断型 | 「XXX是什么」「为什么XXX」 | 「宝宝红屁屁是什么原因」 |
| 认知期 | 知识科普型 | 「XXX原理」「XXX基础知识」 | 「纸尿裤透气性原理」 |
| 考虑期 | 对比评测型 | 「A和B哪个好」「XXX排名」 | 「花王和帮宝适哪个好」 |
| 考虑期 | 横向筛选型 | 「YYY价位XXX推荐」「适合ZZZ人群的XXX」 | 「新生婴儿用什么纸尿裤」 |
| 决策期 | 品牌验证型 | 「XXX靠谱吗」「XXX评价」 | 「花王纸尿裤怎么样」 |
| 决策期 | 购买决策型 | 「XXX多少钱」「XXX哪里买」 | 「花王纸尿裤618价格」 |
| 使用期 | 教程指南型 | 「XXX怎么用」「XXX技巧」 | 「纸尿裤怎么穿不漏」 |

### 第四步：GEO关键词结构化生成

对每个画像x每个决策阶段，生成以下结构的关键词清单：

#### A. 核心词 (Core Keywords)
品牌的品类词、属性词、场景词，构成语义锚点。
格式：`[品类词] + [属性修饰] + [场景修饰]`

#### B. 长尾问题词 (Long-tail Question Keywords)
以自然语言问句形态输出，每个画像>=5条。
格式：`[疑问词] + [画像痛点] + [产品关联]`

#### C. 语义集群 (Semantic Clusters)
围绕一个核心主题聚合5-10个关联关键词，形成内容专题矩阵。
每篇内容覆盖一个集群，而非一个词。

#### D. 信源锚点词 (Authority Anchor Keywords)
传统SEO高权重词 + 行业术语 + 数据引用词，提升AI引用概率。
格式：`[权威机构/研究] + [数据/观点] + [品类]`

### 第五步：内容覆盖方案

基于关键词清单，输出内容策略：

1. **必须覆盖的内容类型**（按优先级排序）：
   - 定义型内容（What is XXX）
   - 对比型内容（A vs B）
   - 指南型内容（How to XXX）
   - 列表型内容（Best XXX / Top N）
   - 数据型内容（统计、报告引用）
   - FAQ型内容（常见问题解答）

2. **内容矩阵建议**：为每个语义集群建议1-3篇内容主题，含标题方向

3. **信源建设建议**：需要在哪些平台建立引用源（Wikipedia条目、行业报告、学术论文引用、官方文档、权威媒体）

## 输出格式

完成后以Markdown表格输出如下结构：

### 1. 画像概览表
| 画像名称 | 人群特征 | 核心需求 | 决策阶段分布 |

### 2. 画像x阶段关键词矩阵
| 画像 | 阶段 | 核心词 | 长尾问题词(3-5条) | 语义集群标签 |

### 3. 语义集群与内容规划
| 集群主题 | 覆盖关键词数 | 建议内容类型 | 标题方向建议 | 优先级 |

### 4. GEO核心词清单（汇总）
将所有核心词按搜索意图分类汇总：
- 信息型关键词（N个）
- 对比型关键词（N个）
- 交易型关键词（N个）
- 导航型关键词（N个）

### 5. 信源建设检查清单
- [ ] 行业定义/概念页是否有品牌被引用
- [ ] 权威第三方是否有产品评测/引用
- [ ] 是否有可被AI抓取的结构化数据（FAQ Schema、HowTo Schema）
- [ ] 竞品在AI引擎中的曝光情况对比

## 行业套用模版速查

根据行业快速套用画像维度和关键词方向：

### 消费品（快消/美妆/母婴/食品）
核心画像维度：年龄、性别、使用场景、价格敏感度、成分党/功效党
关键词方向：成分安全性、使用教程、横向对比测评、性价比排行、囤货攻略
典型长尾词形态：「XXX成分安全吗」「敏感肌用什么XXX」「XXX和YYY区别」

### SaaS / 企业软件
核心画像维度：公司规模、岗位角色（决策者/使用者）、预算范围、部署方式偏好
关键词方向：功能对比、定价透明度、集成能力、安全合规、ROI测算
典型长尾词形态：「XXX和YYY功能对比」「XXX多少钱一年」「小公司用什么XXX」

### 教育/培训
核心画像维度：学段、学科、目标（应试/兴趣/技能）、学习方式偏好
关键词方向：学习方法论、课程对比、考试政策、就业前景、师资评价
典型长尾词形态：「零基础怎么学XXX」「XXX和YYY哪个更适合孩子」

### 医疗健康
核心画像维度：症状、年龄、就医阶段、信息来源偏好
关键词方向：症状自查、治疗方案对比、药品说明、医生/医院评价、预防科普
典型长尾词形态：「XXX症状是什么原因」「XXX需要手术吗」「XXX药副作用」

### 金融/保险
核心画像维度：人生阶段、风险偏好、资产规模、保障需求类型
关键词方向：产品条款解读、收益对比、避坑指南、政策解读、理赔流程
典型长尾词形态：「XXX保险值得买吗」「XX岁买什么保险」「XXX划算吗」

### 房地产/家居
核心画像维度：购房目的、预算、城市/区域、户型偏好、装修风格
关键词方向：区域分析、户型对比、装修攻略、避坑指南、政策解读
典型长尾词形态：「XXX楼盘怎么样」「XX预算能买哪里」「装修XXX要注意什么」

## 质量控制

关键词生成完成后自检：
- 每条核心词是否可以对应到具体画像？如果不能，要么补充画像，要么删除
- 词与词之间是否有足够差异化？高度相似的（仅换一个修饰词）合并
- 是否覆盖了认知->考虑->决策->使用的全链路？
- 是否有>=30%的问句型长尾词？（AI引擎偏好自然语言问句）
- 是否包含>=3个可被引用的数据/权威信源方向？
