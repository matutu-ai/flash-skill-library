01 / USE CASES

适合用来做什么

  • 风景照片超现实再创作
  • 城市或文化地标波普海报
  • 人物照片黑白与平涂拼贴

02 / PROMPT

Prompt 内容

使用 surreal-pop-collage，把我提供的照片改造成竖版 3:4 超现实波普拼贴。保留主体为清晰可识别的黑白现实锚，从原图推导两至三个平涂色形，并且全图只使用一个有场景来源的不可能巨物；生成后简短说明色彩和巨物的来源。

03 / WORKFLOW

执行流程

  1. 01

    读取照片并提取锚点主体、区域边界、原生色、动势与场景典故

  2. 02

    从原图推导两至三个平涂色形

  3. 03

    选择唯一一个源自场景的不可能巨物

  4. 04

    编译四段式图像提示词并生成作品

  5. 05

    按识别度、单一巨物、来源、平涂与明亮度完成质量检查

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    一张用户提供的风景、城市、人物或文化地标照片，以及可选的画幅和表达方向。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / OUTPUT

你会得到

  • 超现实波普拼贴图像
  • 一至三句色形与巨物来源说明
  • 用户明确要求时提供完整生成提示词

06 / REQUIREMENTS

使用前确认

  • 需要可接收参考图的图像生成工具。
  • 主体需保持可识别；色形和唯一巨物都必须能从原图或场景典故中找到来源。
  • 生成提示词不放中文文字；中文标题需要后期排版。
