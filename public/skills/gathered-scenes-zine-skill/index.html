01 / USE CASES

适合用来做什么

  • 保留真实照片的纸感实景拼贴
  • 不保留原照片的原创影像蒸馏
  • 以字体和层级驱动的莫兰迪电影海报

02 / PROMPT

Prompt 内容

使用 gathered-scenes-zine-skill 集合索引分析我提供的照片与创作目标，只选择一个最合适的子 Skill：保留真实现场时选 scenes-gathered-zine-v1-3，不保留照片、重新表达情绪时选 scene-distillation-zine-v1-3，需要电影标题与版式时选 morandi-cinematic-poster-zeejay。选择后严格按对应原始 SKILL.md 执行。

03 / WORKFLOW

执行流程

  1. 01

    读取用户照片、希望保留的关系和表达目标

  2. 02

    在实景拼贴、影像蒸馏与莫兰迪电影海报中选择一个子 Skill

  3. 03

    按所选子 Skill 的正式入口完成场景分析与构图

  4. 04

    生成图像并按所选入口的输出规则交付

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    一张用户提供的真实照片，以及希望保留的主体关系、文字语言、情绪方向或电影海报诉求。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / OUTPUT

你会得到

  • 纸感实景拼贴海报
  • 影像蒸馏原创插画
  • 莫兰迪电影感摄影海报

06 / REQUIREMENTS

使用前确认

  • 需要可接收参考图的图像生成工具。
  • 必须先选择一个子 Skill，并以其原始 SKILL.md 为执行依据。
  • 许可证仅允许个人非商业使用；商业、公司或客户用途需要 Zeejay0 事先书面许可。
