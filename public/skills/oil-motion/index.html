Oil Motion

把滚动，变成一段故事

将滚动、拖拽等交互意图转换为动效方案、动画素材与网页运行时，明确画面如何推进、停住和退回。

  • 网页动效
  • 滚动交互
  • 动画时间轴
  • Motion Design

01 / USE CASES

适合用来做什么

  • 设计由滚动推进并可反向退回的网页叙事
  • 制作由指针、拖拽、触摸或设备方向驱动的产品动效
  • 将角色、材质、遮挡等语义变化转换为可运行的动画素材

02 / PROMPT

Prompt 内容

使用 oil-motion，为公开 Skill 集合网站设计档案抽屉随滚动打开的动效，停止滚动时定格，向上滚动时退回。

03 / WORKFLOW

执行流程

  1. 01

    锁定主体、视觉、交互、连续性、画幅和目标设备

  2. 02

    建立关键帧、片段、播放策略与质量目标

  3. 03

    先制作并验收首组关键帧、首段视频和真实页面挂载

  4. 04

    根据背景与时间控制选择媒体格式和运行时控制器

  5. 05

    逐段生成、验收、编译时间轴并接入网页运行时

  6. 06

    在目标尺寸、DPR、反向操作、移动端和降级条件下验收

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    页面用途、主体与风格、交互方式、目标设备，以及已有图片或视频。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / OUTPUT

你会得到

  • 视觉与交互方案
  • 关键帧及动画生产计划
  • 素材时间轴与网页运行时

06 / REQUIREMENTS

使用前确认

  • 生成与处理素材需要 Python 3、Pillow、ffmpeg 和 ffprobe。
  • 视频生成需要配置相应模型服务。
  • 下载提供 SKILL.md 单文件预览；完整流程还需要配套 scripts、references 和 assets。
