01 / USE CASES

适合用来做什么

  • 产品与人物商业视频提示词
  • 广告 Brief 或分镜导演化
  • 参考视频结构拆解与原创方案
  • 已有 Seedance 提示词诊断优化

02 / PROMPT

Prompt 内容

使用 seedance-2-5-prompt，把我提供的产品、人物、场景素材和广告 Brief 编排为可直接投喂 Seedance 2.5 的提示词。锁定产品与人物身份，按素材职责设计时间轴、镜头与声音，并完成 Human Realism、连续性、Prompt Readiness 和生成前风险检查。

03 / WORKFLOW

执行流程

  1. 01

    识别并规范产品、人物、场景、参考素材与广告目标

  2. 02

    分析主体并建立产品锁与人物身份锁

  3. 03

    设计创意结构、Hook、分镜、镜头语言与声音

  4. 04

    编译 Seedance 2.5 可执行提示词

  5. 05

    检查人物真实感、连续性、可拍性与生成前风险

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    产品、人物或场景图片，产品资料，参考视频，完整分镜，广告 Brief，已有提示词或混合视频创意。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / PLATFORM USE

豆包、千问怎么使用

豆包 / 即梦（具备 Seedance 2.5 能力时）

接收本 Skill 编译后的可执行视频提示词，实际生成依赖平台提供相应模型能力。

  1. 先提供产品、人物或场景图片、产品资料、参考视频、广告 Brief 或已有提示词。
  2. 按正式入口选择 ONE-SHOT PROMPT、SHOT-BY-SHOT PROMPT 或 DIRECTOR PACKAGE，并完成产品锁、人物身份锁、连续性与风险检查。
  3. 将最终提示词复制到具备 Seedance 2.5 能力的豆包或即梦入口，生成前核对人物、产品、声音、版权和授权条件。
  • 本 Skill 负责导演编排与提示词编译，不代替豆包或即梦提交生成任务。
  • 完整流程还需要源仓库中的 QUICK-START、workflow、template、schema 与 Human Realism 资源。

06 / OUTPUT

你会得到

  • ONE-SHOT PROMPT
  • SHOT-BY-SHOT PROMPT
  • DIRECTOR PACKAGE

07 / REQUIREMENTS

使用前确认

  • 实际视频生成需要 Seedance 2.5、即梦或豆包的相应能力。
  • 完整流程需要源仓库中的 QUICK-START、workflow、template、schema 与 Human Realism 资源。
  • 本 Skill 不承担海外市场研究、TikTok 趋势研究或广告投放策略。
