01 / USE CASES

适合用来做什么

  • 企业 GEO 关键词规划
  • 企业与垂直业务画像生成
  • 内容矩阵与发布策略制定
  • GEO 验证与缺口分析

02 / PROMPT

Prompt 内容

使用 geo-keyword-profile-template 分析我提供的企业资料。先说明 GEO V3 框架、已有事实与资料缺口，再按正式流程生成简约版关键词和九大画像；不要虚构企业、案例、资质、数据或验证结果。

03 / WORKFLOW

执行流程

  1. 01

    清洗企业资料并区分事实、证据与缺失项

  2. 02

    建立企业 GEO Profile、行业研究与竞争研究

  3. 03

    生成搜索意图、关键词矩阵、九大画像与垂直画像

  4. 04

    规划内容矩阵与动态发布策略

  5. 05

    执行 GEO 验证、缺口分析、内容补强与再次验证

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    企业介绍、产品或服务资料、案例、图片、docx、xlsx、文本或网页链接，以及用户的生成、调整、批量或验证指令。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / OUTPUT

你会得到

  • 企业 GEO Profile 与证据记录
  • 关键词矩阵、九大画像与垂直画像
  • 内容矩阵、发布策略、验证结果与缺口队列

06 / REQUIREMENTS

使用前确认

  • 企业事实与结论需要可验证来源；缺失信息必须明确标注。
  • 完整执行需要按 INDEX.md 路由读取仓库中的 schemas、workflows、templates 与 references。
  • 任何客户语料库读取、创建或更新均需遵守正式入口中的确认规则。
