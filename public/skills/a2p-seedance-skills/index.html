EIGHT PLAYS

八大玩法有哪些

这些是创作案例分类，不是 Seedance 官方模式。选定玩法后，还需按目标平台核对实际可用的生成方式和素材限制。

  1. 01
    截图脚本生成视频

    用分镜脚本图和主体图安排画面段落与节拍。

  2. 02
    视频参考生成视频

    借鉴参考视频的镜头、节奏和氛围，并绑定自有主体。

  3. 03
    动作迁移

    用动作视频约束动作阶段与运动方向，替换成目标主体。

  4. 04
    双角色对话

    结合两个角色参考与对白，保持身份和互动连续。

  5. 05
    主体＋场景＋动作

    用主体图、场景和动作文字完成单场景行动。

  6. 06
    场景参考＋详细分镜

    结合主体图、场景图与镜头时序，控制空间和多镜头顺序。

  7. 07
    九宫格分镜

    用多格故事板明确关键画面及画面推进。

  8. 08
    漫画／手绘变动画

    让漫画、手绘或草图中的静态内容动起来。

01 / USE CASES

适合用来做什么

  • 产品广告与品牌短片的创意方案
  • Seedance 多素材提示词与分镜制作
  • 编号参考图和一键下载素材包
  • 已授权项目的视频生成与审片修复

02 / PROMPT

Prompt 内容

使用 $lingguo-seedance-master，分析我提供的产品资料、图片和视频，区分事实、目标与待确认项。先推荐适合的玩法与 2–3 个创意方向，展开一份完整方案供我选择；确认后再完成编号素材职责表、参考图提示词、分镜和可直接复制的 Seedance 主提示词。核对素材编号、时间轴、连续性和平台限制。只有在我明确要求制作视频时，才继续生成、审片、修复并交付视频文件。

03 / WORKFLOW

执行流程

  1. 01

    读取原始资料，区分已确认事实、目标、限制和暂定假设

  2. 02

    选定适合的玩法与创意方向，提交完整方案供确认

  3. 03

    确认方案后编排素材职责、编号参考图、分镜与结构化提示词

  4. 04

    核对平台能力、素材绑定、时间轴与连续性，打包交付

  5. 05

    已获视频制作授权时继续生成、逐镜审片、修复并交付成片

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    产品或主题资料、目标受众和平台、时长画幅、已有文字/图片/视频/音频，以及希望保留的事实与风格。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / PLATFORM USE

平台使用方法

Codex

安装源仓库中的 lingguo-seedance-master 后，给出真实素材和制作目标；先确认创意，再让它完成素材与提示词交付。

  1. 打开 GitHub 技能库，下载完整仓库；将 lingguo-seedance-master 连同 references 和 scripts 安装到 Skills 目录。
  2. 新建对话，调用 $lingguo-seedance-master，提供产品资料、已有素材、平台、时长、画幅和必须保留的事实。
  3. 先查看玩法和完整创意方案，选定玩法与方向。
  4. 让它生成编号素材职责表、分镜、主提示词和必要的分段提示词，并核对素材编号。
  5. 需要实际制作视频时明确提出；取得视频文件后再按审片结论修复。
  • 仅下载本页的入口说明不足以运行完整 Skill，需使用源仓库中的参考文件和脚本。
  • 静态预览、后期预演和 Seedance 成片应分别标明。

06 / OUTPUT

你会得到

  • 可确认的完整创意方案
  • 素材职责、编号参考图与分镜
  • 可复制的 Seedance 主提示词及必要的分段提示词
  • 已授权时交付视频文件、审片结论与修复记录

07 / REQUIREMENTS

使用前确认

  • 完整使用需要源仓库中的 SKILL.md、references 和打包脚本。
  • 实际生成视频需要可用的 Seedance 平台入口，并遵守当前平台素材规则。
  • 品牌、产品和客户事实只能来自用户提供或可核查的资料。
