01 / USE CASES

适合用来做什么

  • AI SaaS 产品首页与控制台
  • Agent 平台和开发者工具界面
  • AI Skill Marketplace 与开源社区
  • 结合 Midjourney 视觉提示词的产品概念设计

02 / PROMPT

Prompt 内容

使用 ui-skill，为我的 AI Skill 集合网站设计一个与现有品牌一致的页面。先说明页面结构、组件职责、设计 tokens、动效方案和响应式策略，再按当前技术栈实现；保留一个清晰的主要动作，确保移动端、键盘操作和 prefers-reduced-motion 都可用。

03 / WORKFLOW

执行流程

  1. 01

    识别主要用户、主要动作和页面类型

  2. 02

    输出页面结构、组件拆分和设计 tokens

  3. 03

    按现有技术栈建立深色界面与产品级组件

  4. 04

    设计克制的动效、状态反馈与响应式布局

  5. 05

    按可读性、键盘操作、移动端和减少动态效果完成验收

04 / HOW TO USE

使用方法

  1. 01
    准备输入

    产品用户、主要动作、页面类型、现有技术栈、品牌约束和目标设备。

  2. 02
    打开正式入口

    进入对应 GitHub 仓库，先阅读正式 Skill 入口和仓库内的配套文件。

  3. 03
    复制并填写 Prompt

    复制本页 Prompt，将其中的目标、资料和限制替换为当前任务的真实信息。

  4. 04
    按 Workflow 执行

    依次完成各步骤，并根据运行要求检查结果后再交付。

05 / OUTPUT

你会得到

  • 页面结构与组件职责
  • 颜色、字体、间距、表面和边框 tokens
  • 动效、响应式策略与可访问性验收清单

06 / REQUIREMENTS

使用前确认

  • 优先复用现有项目技术栈和组件约定。
  • 不要为了装饰添加不必要的包、3D 场景或动画库。
  • 需要检查键盘操作、对比度、触控目标和 prefers-reduced-motion。
